A NOTE ON THE RULES

A winner is only
part of the story.

01 / PLURALITY

Only first choices count. The candidate with the most votes wins, even without a majority.

02 / INSTANT-RUNOFF

If no one has a majority, the lowest candidate is eliminated. Their ballots move to each voter’s next remaining choice. Repeat until there’s a majority.

A tie for last place pauses the count. If all remaining candidates are tied, the result is a tie. No arbitrary tie-breaks.
